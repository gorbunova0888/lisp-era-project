# Роль

Ты работаешь как ИИ-агент внутри учебного проекта.
Собери цельную одностраничную рекламную веб-страницу
из материалов, которые подготовил студент.
Сохраняй авторские решения проекта и не подменяй их
универсальным шаблоном.

# Перед сборкой

1. Прочитай README.md.
2. Полностью прочитай research.md, era.md, concept.md и sources.md.
3. Найди все Markdown-файлы в blocks/ и прочитай их
   по порядку числовых префиксов.
4. Просмотри доступные файлы в assets/.
5. Кратко сформулируй:
   - какой объект и какую эпоху представляет проект;
   - кому адресованы вымышленные курсы и что они обещают;
   - какие блоки входят в страницу и в каком порядке;
   - какие конкретные визуальные правила из era.md нужно соблюдать.
После этого переходи к сборке.

# Источники истины

- research.md — исторические факты и ценность объекта;
- era.md — временной диапазон, технологическая и визуальная среда;
- concept.md — аудитория, обещание, голос и центральная шутка;
- blocks/*.md — набор, порядок, содержание и назначение секций;
- sources.md — подтверждения фактов и визуальные ориентиры;
- assets/ — локальные материалы.

Не меняй эти Markdown-файлы без отдельной команды студента.

# Главная задача

Создай готовый index.html. Страница рекламирует вымышленные
курсы по языку Lisp так, как это могло бы выглядеть в конце
1970-х — 1980-е годы, в эпоху коммерческих Lisp-машин.

Используй blocks/*.md как структуру страницы.
Сохраняй порядок файлов. Не добавляй новые смысловые
секции только ради привычной структуры сайта.
Не придумывай даты, цитаты, рейтинги, известных пользователей
и события. Если для страницы нужен факт, которого нет
в подготовленных материалах, оставь нейтральную формулировку.

Опирайся на era.md и визуальные источники:
- монохромный экран (зелёный или янтарный текст на чёрном);
- моноширинные шрифты;
- плотная вёрстка, рамки, панели, кнопки;
- никаких скруглённых карточек, градиентов, теней, эмодзи;
- никакого минимализма и пустых экранов;
- современные шрифты (Inter, Roboto, San Francisco) не использовать.

Юмор должен поддерживать историческую идею и реальные
свойства Lisp. Ключевая шутка — «код и данные записываются
одинаково» — сквозная для всей страницы.

# Технический результат

- основной файл — index.html;
- страница открывается локально без сервера и сборки;
- CSS можно разместить внутри index.html;
- JavaScript используй только там, где он нужен концепции;
- локальные изображения подключай относительными путями
  из assets/images/;
- внешние библиотеки и сетевые зависимости для просмотра
  не нужны;
- текст остается читаемым на обычном экране ноутбука;
- никакие элементы не перекрывают основное содержание.

# Проверка перед сдачей

Сопоставь index.html с research.md, era.md, concept.md
и каждым файлом blocks/*.md. Убедись, что:

- историческая ценность Lisp понятна из страницы;
- эпоха Lisp-машин узнается по нескольким согласованным признакам;
- каждый подготовленный блок присутствует и выполняет свое назначение;
- тексты не содержат выдуманных исторических утверждений;
- визуальная система поддерживает одну рекламную историю;
- index.html открывается локально.
